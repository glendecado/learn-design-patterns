| Pattern                     | Description                                                    |
| --------------------------- | -------------------------------------------------------------- |
| **Chain of Responsibility** | Passes a request through a chain of handlers.                  |
| **Command**                 | Encapsulates a request as an object.                           |
| **Interpreter**             | Defines a way to interpret a language or grammar.              |
| **Iterator**                | Provides a way to traverse a collection.                       |
| **Mediator**                | Centralizes communication between objects.                     |
| **Memento**                 | Captures and restores an object's previous state.              |
| **Observer**                | Notifies dependent objects when something changes.             |
| **State**                   | Changes an object's behavior based on its current state.       |
| **Strategy**                | Allows interchangeable algorithms or behaviors.                |
| **Template Method**         | Defines an algorithm's structure while allowing steps to vary. |
| **Visitor**                 | Adds operations to objects without modifying their classes.    |
